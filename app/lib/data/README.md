# 데이터 계층

로직 계층의 저장 인터페이스를 SQLite(sqflite)로 구현한다.
DB 스키마·마이그레이션·트랜잭션·직렬화는 이 계층에 한정한다.
`SqliteRoutineStore`에 설정·루틴·기상 기록·실행 스냅샷 저장을 구현했다.
Android에서는 `openDefault()`로 앱 내부 DB를 열고, 호스트 테스트는 명시적 파일 경로와 `databaseFactoryFfi`를 주입한다.

스키마 1의 테이블은 `settings`, `routines`, `wake_records`, `routine_runs`다.
ID·상태·검색 시각·실행 버전은 컬럼이며 상세 모델과 단계 순서는 버전이 있는 스냅샷에 저장한다.
관측·실행 시각은 epoch 마이크로초로 보존하고 읽을 때 UTC `DateTime`을 반환한다. 화면 표시에는 `.toLocal()`을 사용한다.
시간대가 없는 설정 시각은 하루 안의 분 값으로 보존한다.

루틴 수정·삭제는 과거 실행을 변경하지 않는다. 같은 기록 재저장은 멱등적이며 오래된 실행 버전과 종료 기록의 덮어쓰기, 확정·취소 기록의 후보 역행은 거부한다.
알 수 없는 스냅샷 버전이나 손상 데이터는 오류로 반환하며 조용히 초기화하지 않는다.

실제 파일 DB 재개방·입력 보존·불변 기록·상태 보호·손상 처리를 호스트 자동 테스트로 검증했다.
T04·T05의 UI 오류 안내·실제 SQLite 실패 및 에뮬레이터 관측 결과는
[UI 규약 점검](../../../docs/t04-t05-ui-audit.md)에 구분해 기록한다. 실제 물리 기기 검증과 구분한다.
