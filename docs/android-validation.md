- 개발 호스트: Ubuntu 24.04 x86_64.
- SDK: Flutter 3.47.8 / Dart 3.13.7 / Temurin JDK 21.0.13.
- Android SDK API 36 / Build Tools 36.0.0. `flutter doctor -v`의 Android toolchain 통과, 라이선스 승인 상태 확인.

- `flutter build apk --debug` 통과. `app/build/app/outputs/flutter-apk/app-debug.apk` 생성.
- [초안 PR #5](https://github.com/hye6k/aix-2026f-team08/pull/5) 생성으로 GitHub Actions 실행이 시작되었다. 로컬 검사 통과와 원격 CI 결과를 구분하며, 최신 결과는 PR에서 확인한다.
- 실제 기기에서의 초기 화면 실행은 미검증. T01의 기기 선택·실행 완료 조건은 아직 충족하지 않았다.

## 2026-10-31 후속 개발 검증

- 준비한 기능 브랜치를 합친 로컬 검증에서 정적 분석과 테스트 45건이 통과했다. 이 중 4건은 실제 SQLite 파일을 재개방하며 설정→테스트 신호→기상 확인→루틴→복구→도착 계산→기록 보정의 연결을 검증한다.
- 이 테스트에서 활동 신호는 `WakeSource.test`로 명시한 주입 이벤트다. 실제 Android 활동 감지 성공으로 기록하지 않는다.
- 전체 변경 상태의 Android debug APK 빌드를 통과했다.
- 별도 개발 도구 `ProbeActivity`/`ProbeAlarmReceiver`의 debug 및 release APK 빌드를 통과했다. 실제 APK manifest 검사로 실험 Activity·Receiver와 알람·알림 권한이 release에 포함되지 않음을 확인했다.
- Android Emulator 37.2.13과 API 36 이미지를 설치했다. 현재 사용자는 KVM 접근 권한이 없으며, 소프트웨어 모드 실행은 정상 부팅 완료 전에 종료 코드 139로 끝났다.
- Android 앱 실행·OS 신호·예약 알람·소리·진동 검증은 여전히 미완료다. 위 플랫폼 실험 표를 성공으로 변경하지 않았다.
- 재현 방법은 `docs/android-probe.md`의 별도 도구 PR을 따른다. T01 #4와 T02/T17 전체 완료 판정은 실제 관측 후 진행한다.
