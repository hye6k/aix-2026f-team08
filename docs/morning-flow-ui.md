# 계획·기상·루틴 화면

시간 설정과 루틴 관리 화면은 기존 화면을 사용한다. 계획 탭에서 루틴과 목표 날짜를 선택해 단발 계획을 저장하면 계산된 도착·출발·기상·취침 및 적용 알람 시각을 확인할 수 있다. 알람 권한과 적용 대기 재시도도 이 화면에 표시한다.

진행 탭은 기상 후보 확인·취소, 수동 기상 입력, 루틴 시작·단계 완료·건너뛰기·중단과 예상 도착·지각을 제공한다. debug 빌드의 테스트 기상 신호는 실제 Android 화면 켜짐 신호와 구분한다. 기록 탭은 저장된 기상과 루틴 실행을 간단히 표시한다.

계획은 날짜별 단발이며 다음 날 자동 반복하지 않는다. 예상 도착은 입력된 이동 시간과 남은 준비를 바탕으로 계산한다. 위치·교통 상황은 반영하지 않고, 루틴 완료 후에는 지금 출발한다는 가정이다. 기상 감지와 소리·진동의 실제 기기 동작은 #17에서 별도로 검증한다.

선택된 마지막 루틴의 계획 해제·삭제, 상세 기록 및 Android 재부팅 후 자동 알람 복구는 이 화면에서 지원하지 않는다.
